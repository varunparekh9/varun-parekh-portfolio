VARUN PAREKH PORTFOLIO — DEPLOYMENT

Files to upload together:
1. index.html
2. VP.jpeg
3. Varun_Parekh_Resume.pdf

GitHub Pages:
1. Create a public repository (example: varun-parekh-portfolio).
2. Upload all three files to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for GitHub to publish the site and use the generated github.io URL as your Portfolio URL.

Do not rename VP.jpeg or Varun_Parekh_Resume.pdf unless you also update index.html.
